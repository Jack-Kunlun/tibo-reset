# 调研：Tibo Reset 这个品类到底长什么样

> 这份文档是立项时的外部事实核查结果。所有结论都标注了来源或标注为「未核实」。
> 工程决策见 `decisions.md`，模型方法论见 `model.md`。

## 一、这个现象是什么

「Tibo Reset」指 OpenAI 核心产品负责人 **Thibault Sottiaux**（@thsottiaux，开发者圈叫 Tibo）
在 X 上宣布重置 Codex / ChatGPT 的用量额度。媒体报道称他桌上有一个实体按钮，按一下全网额度清零重来。

- 他本人轨迹：比利时人 → 谷歌伦敦（地图、DeepMind）→ 2024 年搬到**旧金山**加入 OpenAI →
  2026 年升任 OpenAI 核心产品负责人（ChatGPT + Codex 归他管）。
  来源：新浪财经 2026-06-16《那个帮你重置 Codex 额度的男人》、搜狐/新智元报道、Dev Interrupted 播客。
  **推论（用于时区展示）**：按公开报道他常驻旧金山，因此本项目默认他使用
  `America/Los_Angeles`（太平洋时间）—— 这是**推定，不是他本人声明**，代码里做成可配置项。
- 注意：网上另有一篇把他写成「鲁汶大学博士、2019 年加入 OpenAI」的文章，与其余多篇报道冲突
  （后者一致说他 2024 年从 DeepMind 加入）。那篇未采信。

## 二、已经有人在做了（立项时的现状）

| 类型 | 玩家 | 现状 |
|---|---|---|
| 微信小程序 | 「重置来了」（佬刘，个人主体） | 记录 + 盯 Tibo + 订阅消息提醒；**搜索功能曾被限制**（截图所见，具体原因未核实） |
| 微信小程序 | 「徐公 AI 雷达」 | 2026-08-26 上线，v1.3 已含概率预测；自述 3 周累计 1200 人 |
| 网站 | codex-resets.com | 归档 + 热力图，**暴露公开 JSON API**（本项目冷启动数据来源） |
| 网站 | nextreset.ai | 48h 概率，自标 `EXPERIMENTAL ESTIMATE`；把记录分为 Automatic reset / Banked credit |
| 网站 | 另有 codex-reset.com、reset.aixiaobo、when-does-it-refresh、willcodexquotareset、reset.aitrent | 功能与上述高度重叠 |
| 内容号 | 小红书「Codex 今天重置了吗」 | 粉丝 1000+，每天发 |

**结论：赛道拥挤，且「概率预测」这一层已经被做了。** 靠同一个功能入场只能打价格战。

## 三、各家统计口径互相打架

同一批事件，不同站点的「平均间隔」有 **7.2 / 8.0 / 8.7 天** 三个版本，最长 67.7 天。
差异原因是「哪些算一次重置」没有公认定义（是否把 banked credit 计入、以公告时间还是生效时间起算）。
本项目在自建记录里显式区分 `type: reset | credit`，并把口径写进 `docs/model.md`。

## 四、这个品类的真实风险

1. **机制正在退场。** nextreset.ai 已把记录分成 `Automatic reset` 与 `Banked credit`（额度券）两类；
   本项目自建数据里 53 条记录中有 3 条是发券型。从「无条件撒福利」转向发券，意味着
   「Tibo 一按按钮全世界欢呼」这个现象本身有保质期。
2. **承诺已经兑现完。** 2026-08-30 那次重置是纪念 2500 万用户，而最初的说法是
   「每增 100 万用户重置一次，到 1000 万为止」。
3. **需求频次低。** 平均 7~8 天一次事件 → 用户平均每 8 天才想起这个工具一次，
   留存天花板由事件频率决定，不由产品质量决定。
4. **关键词已被污染。** 搜索「Tibo 重置」前排混进 AI 内容农场编的假文
   （把 Tibo 说成某款游戏、编造「官方已确认本周重置时间」），获客成本上升。

## 五、工程侧的硬约束（实测）

| 约束 | 实测证据 |
|---|---|
| **x.com 在国内不可达** | 连续 3 次 `curl` 全部 `http=000`、各 15.5s 超时；同期 `github.com`、`codex-resets.com` 正常（后者 0.7s） |
| X 官方 API 太贵 | Basic 档约 $200/月 |
| 免登录可抓 X | `x.com/<account>` 未登录 HTML 内嵌 React Server Components 载荷，正文可正则抽取（见 `docs/model.md` 附录） |
| 小程序域名要备案 | 境内主体小程序的 request 合法域名必须 ICP 备案；个人主体另禁 web-view / 微信支付 / UGC |
| 流量主门槛 | 已上线 + 累计 UV≥1000 + 微信认证；1200 人量级的 CPC 收入约等于零 |

## 六、立项结论

- **当生意：不建议。** 天花板低、留存差、护城河为零、合规有雷、生死握在别人手里。
- **当作品 / 引流：做。** 技术含量对目标读者有吸引力，一个周末可完成，
  且「节奏在加速」「校准 vs 区分度」这些分析结论本身就有传播价值。
- 因此本项目的定位是 **作品 + 引流**，不是商业产品。这就决定了后面的两个关键取舍：
  载体选网页（可转发、可收录），内核选「描述分布」而不是「兜售预测」。
